隐私政策

更新时间：2026年8月13日  |  矛盾 v1.6

一、信息收集

「矛盾」是一款本地优先的个人成长管理应用。我们严格保护您的隐私。

我们收集以下信息：

  • 您主动创建的习惯数据（名称、描述、打卡记录）
  • 应用使用偏好（主题设置）

所有数据均存储在您的设备本地（LocalStorage / SharedPreferences），不会上传至任何服务器。

二、数据使用

我们仅在您的设备上使用收集的数据，用于：

  • 计算习惯连胜、完成率等统计数据
  • 展示成就徽章和历史记录
  • 生成矛盾分析报告

三、数据共享

我们不会与任何第三方分享您的个人数据。您导出的 JSON 数据文件由您自行保管。

四、数据安全

您的数据存储在浏览器本地存储中，安全性取决于您的设备安全设置。建议使用设备锁屏密码保护。

五、数据删除

您可在应用「设置」→「清除所有数据」中随时删除全部本地数据。卸载应用也会清除相关本地存储。

六、Cookies

本应用不使用 Cookie 进行追踪。Web 版本使用必要的本地存储以保存您的偏好设置。

七、儿童隐私

本应用不面向13岁以下儿童设计，亦不会故意收集儿童信息。

八、第三方服务

本应用使用以下第三方服务（仅在您主动使用时）：

  • Flutter（Google）— 应用框架
  • GitHub Pages — Web 托管

九、联系我们

如您对本隐私政策有任何疑问，请通过 GitHub Issues 与我们联系。

我们有权在必要时更新本政策，更新版本将在应用内公告。
