## 2. 一句话简介（5-16 个汉字）

**主推：** 听着读英文，生词自然记

**备选：** 边听边读，把英语读顺

## 3. 应用详细介绍（≥50 字）

听阅是一款本地优先的英语听读学习应用。导入 EPUB 或粘贴文章，点按任意单词即可查词并加入生词本；生词按遗忘曲线自动排期复习。内置离线语音合成与离线词典，核心功能无需联网即可使用；多种阅读模式（普通阅读、分栏对照、仿生阅读、快速阅读、挖空、听写、回译等九种）满足精读泛读不同需求。你的书籍与学习数据全部保存在手机本地，无需注册，卸载即彻底删除。

## 5. 权限用途说明（商店后台逐条填写）

| 权限 | 用途 |
| --- | --- |
| 网络访问（INTERNET） | 下载词典数据与翻译语言模型；抓取你主动添加的 RSS 订阅与文章链接；连接你自行配置的翻译/朗读服务 |
| 读取外部存储（READ_EXTERNAL_STORAGE，仅 Android 12 及以下） | 通过系统"打开方式"导入你选择的 EPUB 电子书文件 |
| 发送通知（POST_NOTIFICATIONS） | 在你设定的时间发送生词复习提醒（默认关闭，需你主动开启） |
| 设置精确闹钟（SCHEDULE_EXACT_ALARM） | 保证复习提醒在你设定的时间准时触发 |
| 开机自启（RECEIVE_BOOT_COMPLETED） | 手机重启后重新调度已设置的复习提醒闹钟，避免提醒丢失 |
| 保持唤醒（WAKE_LOCK） | 朗读过程中防止系统休眠中断朗读 |
| 震动（VIBRATE） | 翻页等操作的触感反馈 |
