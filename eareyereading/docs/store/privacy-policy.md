# 「听阅」隐私政策

**更新日期：2026 年 9 月 13 日 ｜ 生效日期：2026 年 9 月 13 日**

「听阅」（以下简称"本应用"）是由个人开发者（以下简称"开发者"）提供的本地优先的英语听读学习工具。开发者在为您提供本应用服务的过程中，将严格遵循《中华人民共和国网络安全法》《中华人民共和国个人信息保护法》《中华人民共和国数据安全法》及相关法律法规的要求，保护您的个人信息与隐私安全。

请您在使用本应用前仔细阅读本政策。**您点击"同意"并继续使用本应用，即表示您已充分理解并同意本政策全部内容。**

## 一、我们如何处理您的信息

### 1.1 本应用不收集的信息

本应用**不要求注册或登录任何账号**，不收集您的手机号码、电子邮箱、身份证件信息、精确地理位置信息、通讯录、通话记录、短信、相册、麦克风录音等任何个人身份信息。

### 1.2 您主动产生的数据（仅存储在您的设备本地）

- **书籍与文档**：您导入的 EPUB 文件、RSS 订阅源、文章链接；
- **学习数据**：生词本、复习记录、阅读进度、打卡记录；
- **偏好设置**：主题、字号、朗读配置、翻译配置等。

以上数据全部通过本地数据库（Room）与本地存储（DataStore/应用私有目录）保存在您的设备上，**开发者不设立任何服务器存储您的上述数据，不进行云端同步**。您清除应用数据或卸载本应用后，这些数据将被彻底删除且无法恢复。

### 1.3 联网功能说明

本应用为"本地优先"设计，核心功能（本地 TTS 朗读、本地词典、本地翻译兜底）均在设备本地完成。以下联网功能**仅在使用时触发**，且仅传输实现该功能所必需的内容：

| 联网功能 | 触发时机 | 传输内容 | 数据去向 |
| --- | --- | --- | --- |
| 词典数据更新 | 您进入词典页或手动刷新 | 词典清单与词典数据文件 | jsDelivr CDN（公共开源仓库） |
| 在线翻译模型下载 | 您首次使用 ML Kit 离线翻译 | 语言模型文件 | Google ML Kit 模型服务器 |
| LLM 翻译（可选） | 您配置了自定义 LLM API 并发起翻译 | 选中的文本片段 | 您自行填写的 API 服务商 |
| RSS / 文章抓取 | 您添加订阅源或打开文章链接 | 您填写的 URL | 对应的第三方网站 |
| 自定义 TTS 音源（可选） | 您配置了 HTTP TTS 音源并朗读 | 合成请求文本 | 您自行填写的音源服务方 |

## 二、权限使用说明

本应用按"最小必要"原则申请系统权限，全部权限与功能的对应关系如下：

| 权限 | 权限名称 | 用途说明 | 是否可拒绝 |
| --- | --- | --- | --- |
| INTERNET | 网络访问 | 实现上表所列联网功能 | 可（联网功能不可用，本地功能不受影响） |
| READ_EXTERNAL_STORAGE | 读取存储（Android 12 及以下） | 通过系统"打开方式"导入您选择的 EPUB 文件 | 可（改用系统文件选择器导入） |
| POST_NOTIFICATIONS | 发送通知 | 发送复习提醒通知（需您主动开启） | 可（仅影响提醒通知） |
| SCHEDULE_EXACT_ALARM | 设置精确闹钟 | 在您设定的时间准时发出复习提醒 | 可（提醒可能延迟） |
| RECEIVE_BOOT_COMPLETED | 开机自启 | 手机重启后重新调度已设置的复习提醒闹钟 | 可（重启后提醒可能失效） |
| WAKE_LOCK | 保持唤醒 | 朗读过程中防止系统休眠中断朗读 | 可 |
| VIBRATE | 震动 | 翻页等交互的震动反馈 | 可 |

## 三、第三方 SDK 说明

本应用集成以下第三方组件。除表中说明外，我们不会向任何第三方共享您的个人信息：

| 组件 | 提供方 | 用途 | 涉及的数据 |
| --- | --- | --- | --- |
| ML Kit Translate | Google | 设备端离线翻译 | 使用时向 Google 服务器下载语言模型；翻译文本在本地处理 |
| sherpa-onnx + Kokoro 模型 | 开源社区（Apache-2.0） | 设备端离线语音合成 | 无（完全本地运行，不联网） |
| AndroidX / Material / Compose | Google | 应用基础框架 | 无 |
| Room / DataStore | Google | 本地数据存储 | 无 |
| Coil | 开源社区 | 封面图片渲染 | 无 |

## 四、数据存储与安全

1. 本应用的全部用户数据仅存储在您设备的应用私有目录中；
2. 本应用不包含任何开发者自建服务器，不存在服务器端数据泄露风险；
3. 您可随时在系统设置中清除本应用数据，或在设置页内使用"数据导出"自行备份；
4. 我们将采取合理的加密与隔离措施保护本地数据安全，但不能保证绝对安全。

## 五、未成年人保护

本应用为学习类工具，主要面向普通用户。若您是未满 14 周岁的未成年人，请在监护人陪同下阅读本政策，并在征得监护人同意后使用本应用。本应用不主动面向未成年人收集任何个人信息。

## 六、您的权利

1. **查询与更正**：您的全部数据均在本地，可在应用内直接查看与修改；
2. **删除**：您可在应用内删除生词、记录，或通过卸载应用彻底删除全部数据；
3. **注销**：本应用无需注册账号，不涉及账号注销；如需删除全部本地数据，卸载即可；
4. **撤回同意**：您可随时在系统设置中关闭相关权限；您也可以选择不再使用本应用。

## 七、政策的变更

我们可能适时更新本政策。重大变更时，我们将在应用内或本政策发布页面显著提示。请您定期查阅以了解最新内容。
